# Product Roadmap

## Near-Term Goals (Q3 2026)

- [x] **IEEE Literature Synthesis Engine**: Single-click academic paper generation with inline citations.
- [x] **Unified Reference System**: Standardized IEEE reference citation formatting across PDF, Word, LaTeX, and BibTeX exports.
- [x] **Multi-Format Academic Exporter**: Export research to PDF, LaTeX, BibTeX, DOCX, and Markdown.
- [ ] **Direct Zotero & Mendeley Sync**: Export citations directly to reference management tools.

## Mid-Term Goals (Q4 2026)

- [ ] **Multi-Document Comparative Matrix**: Automated side-by-side methodology and metrics extraction across 10+ PDFs.
- [ ] **Live ArXiv API Integration**: Fetch latest peer-reviewed preprints directly within the research workspace.
- [ ] **Interactive Citation Graph**: Visual graph visualization linking papers, authors, and co-citations.

## Long-Term Goals (2027)

- [ ] **Collaborative Peer Review Mode**: Real-time multi-author annotation and review workflow.
- [ ] **Automated LaTeX Journal Template Exporter**: One-click formatting for ACM, Springer, and Nature templates.

# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-08-02

### Added
- Standard repository management files (`LICENSE`, `CONTRIBUTING.md`, `ARCHITECTURE.md`, `ROADMAP.md`, `CHANGELOG.md`).
- Unified IEEE reference formatting in academic paper modal, converting document citations to standardized IEEE bibliographic citations.
- LaTeX (`.tex`) and BibTeX (`.bib`) export features for research reports.

### Changed
- Standardized academic synthesis outputs to focus strictly on domain research findings rather than self-referential agent jargon.
- Enhanced `@media print` styling for clean, native browser printing and PDF saving.

### Fixed
- Fixed reference formatting inconsistency where citations appeared as separate styled boxes instead of unified numbered IEEE references.

## [1.1.0] - 2026-07-20

### Added
- Multi-document knowledge base indexing and page-level anchor mapping.
- Interactive research workspace with query decomposition and grounded synthesis.

## [1.0.0] - 2026-07-01

### Added
- Initial release of the Research Intelligence Platform.
